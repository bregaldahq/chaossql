ChaosSQL: Deterministic SQL Concurrency & Isolation Fuzzer

Catch database concurrency bugs before production does. ChaosSQL is an open-source (MIT) Go tool that stress-tests PostgreSQL, MySQL and SQLite with deterministic, seed-reproducible interleavings, detects lost updates, write skew, G2 and other Adya isolation anomalies, and shrinks every failing trace to a 1-minimal counterexample with delta-debugging.

ChaosSQL é um fuzzer open source de concorrência SQL: execuções determinísticas por seed, classificação formal de anomalias de isolamento de Adya e delta-debugging causal para PostgreSQL, MySQL e SQLite.
