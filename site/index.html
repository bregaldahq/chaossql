Academic Foundations & Rigorous Systems

Built on Formal Concurrency Research

ChaosSQL replaces heuristic guesswork with rigorous isolation theory, provable scheduling bounds, and algorithmic test case minimization.

01 / GRAPH THEORY FORMAL VERIFICATION

Adya Cycle Classification

Constructs dynamic Direct Serialization Graphs $DSG(H) = (V, E)$ tracking write-read ($wr$), write-write ($ww$), and read-write anti-dependency ($rw$) edges to categorize anomalies (P4, A5B, A5A, G0, G2).

Atul Adya (MIT 1999) 100% Deterministic
02 / PROBABILITY BOUNDS PCT SCHEDULING

PCT-SQL Priority Scheduling

Adapts Probabilistic Concurrency Testing to SQL engines. Mathematically guarantees finding isolation bugs of bug-depth $d$ with lower bound $\mathbb{P} \ge rac{1}{n \cdot k^{d-1}}$, avoiding deadlocks and thread starvation.

Burckhardt et al. (ASPLOS 2010) Provable Guarantee
03 / TRACE MINIMIZATION DELTA-DEBUGGING

Causal Delta-Debugging ($ddmin$)

Partitions noisy execution histories of 100+ concurrent operations to isolate the exact 1-minimal subset of 2 steps required to reproduce the anomaly in <200ms.

Andreas Zeller (IEEE TSE 2002) 90% Noise Cut
04 / OBSERVABILITY LOCAL WEB SERVER

Interactive Trace Visualizer

Embedded HTTP engine on port 8090 with microsecond Gantt swimlanes per goroutine, interactive Adya conflict graphs, and deep parameter query inspector.

chaossql ui 127.0.0.1:8090
05 / CI/CD GATING SECURITY GATING

OASIS SARIF 2.1.0 & GitHub

Converts database isolation flaws directly into security findings in GitHub Code Scanning with 9 formal rules, JUnit XML test results, and PR step summaries.

OASIS Standard 9 Formal Rules

Zero CGO & Pure Go

Compiled with CGO_ENABLED=0 using modernc.org/sqlite. Completely static binary with zero external C libraries and micro-benchmark throughput of 13.9M operations/sec.
