# ChaosSQL v1.3.0 Release Notes

**Release Date:** September 5, 2026  
**Tag:** `v1.3.0`  
**Theme:** In-Browser WebAssembly Studio & Client-Side Verification Engine  

---

## Executive Summary

**ChaosSQL v1.3.0** marks a major milestone in database concurrency research and developer accessibility. Prior to v1.3.0, evaluating transaction isolation levels, detecting Adya anomalies ($G0$, $A3$, $A5A$, $A5B$, $G1a$, $G1c$, $G2$, $G\text{-DL}$), and synthesizing 1-minimal causal counterexamples required local Go CLI or Docker installations.

With v1.3.0, the core ChaosSQL engine—including the deterministic PRNG fuzzer, micro-jitter scheduler, Adya Direct Serialization Graph (DSG) cycle classifier, Elle-style register linearizability checker, and Zeller causal delta-debugging ($ddmin$) shrinker—is compiled directly to **WebAssembly (`GOOS=js GOARCH=wasm`)**. The entire formal verification engine executes **100% client-side inside browser Web Workers**, enabling instant, zero-install interactive experimentation with complete data privacy and zero server-side state.

---

## Key Highlights & Capabilities

### 1. In-Browser WebAssembly Engine (`site/assets/chaossql.wasm`)
- **Zero-CGO Pure-Go Compilation**: Compiled with `-ldflags="-s -w -X main.version=1.3.0" -trimpath` into a static WebAssembly binary under 8MB uncompressed (< 2.2MB gzipped / brotli).
- **Virtual SQL Driver Bridge**: Operates via an isolated in-memory SQL virtual engine and driver bridge, decoupling transactional execution from host OS operating system primitives.
- **Identical Formal Guarantees**: Retains the exact same mathematical properties, cycle classification algorithms, and $ddmin$ 1-minimality proofs as the native CLI.

### 2. Dedicated Web Worker RPC Protocol (`site/assets/wasm-worker.js`)
- **Non-Blocking 60 FPS Execution**: Heavy CPU execution, graph cycle traversals, and $ddmin$ reduction loops are isolated within a dedicated Web Worker, guaranteeing the browser main UI thread never drops frames.
- **Asynchronous Event Protocol**:
  - `INIT`: Loads `wasm_exec.js` and instantiates `chaossql.wasm`.
  - `VALIDATE`: Performs AST syntax and schema validation on YAML scenarios.
  - `RUN`: Dispatches concurrent transactions and streams real-time progress events (`PROGRESS`, `CYCLE_DETECTED`, `SHRINK_PROGRESS`, `COMPLETE`).
  - `CANCEL`: Aborts running schedule instantaneously via Go `context.WithCancel`.

### 3. Interactive Web Playground Studio (`site/#/playground`)
- **10 Canonical Preset Scenarios**: 1-click loading of all flagship test cases:
  1. *Fintech Lost Update* ($P4$)
  2. *E-Commerce Inventory Oversell* ($A3$)
  3. *Hospital Write Skew* ($A5B$)
  4. *Financial Audit Read Skew* ($A5A$)
  5. *Auction Bidding Dirty Write* ($G0$)
  6. *Crypto Arbitrage Circular Information* ($G1c$)
  7. *Flash Crash Liquidation Dirty Read* ($G1a$)
  8. *Ticket Seat Reservation Anti-Dependency* ($G2$)
  9. *Deadlock Cycle & Timeout Diagnostics*
  10. *Foreign Key Cascade Deadlock & Lock Hierarchy Inversion* ($G\text{-DL}$)
- **Live YAML Scenario Editor**: Syntax-highlighted YAML editor with real-time validation and reactive error markers.
- **Interactive Runtime Controls**: Interactive sliders for worker concurrency (1–8), test iterations (5–50), micro-jitter perturbation (0–50ms), and deterministic PRNG seed.
- **Dynamic Adya Conflict Graph**: Responsive SVG visualization rendering transactions as nodes ($T_1, T_2, ...$) and directed conflict dependencies ($ww, wr, rw$) with pulsing anomaly cycle animations.
- **Microsecond Gantt Swimlane**: Interactive timeline illustrating worker goroutine interleavings and statement execution intervals.
- **Causal Delta-Debugging Inspector**: Visual side-by-side comparison showing original schedule vs the 1-minimal causal reproduction schedule.

### 4. Dynamic Bilingual Localization (PT / EN)
- **Seamless Real-Time Language Switcher**: Full bilingual toggle (`PT` / `EN`) in the portal header.
- **Dynamic Trace Localization**: Execution traces, status badges (`executing`, `violated`, `serializable`, `retrying`), timeline swimlane markers, and interactive console logs translate dynamically in real time without reloading the application.
- **Automated i18n Symmetry Gate**: Guarded by `tools/audit_i18n.js` and `tools/test_playground_ui.js` Suite 6 (100% translation key parity).

### 5. Performance Telemetry & Bounded Resource Guarantees
- **Frame Budget Compliance**: Adya graph SVG layout generation achieves average latency < 0.1ms (P95 < 0.2ms), well within the 16.66ms frame budget required for 60 FPS.
- **Memory Bounds**: Continuous 100-iteration stress testing (`tools/headless_worker_stress.js` and `site/assets/wasm-bench.js`) verifies V8 heap growth < 15MB and WebAssembly linear memory stability (< 32MB growth).

### 6. Automated Quality & Security Verification Gates
- **Automated English Purity Gate (`tools/test_english_purity.js`)**: Permanently ensures that 100% of the repository outside the bilingual `site/` portal remains in English.
- **DOM Structural Integrity Suite (`tools/test_playground_ui.js`)**: Formally asserts that all portal view containers are properly closed first-level siblings under `<main>`, preventing display occlusion regressions.
- **Harness Verification (`tools/harness_check.go`)**: Validates the presence and integrity of all system specifications, ADRs, evals, and tools.

## Upgrade & Compatibility Notes

- **Zero Breaking Changes**: Fully backwards-compatible with all YAML scenarios and CLI configurations from ChaosSQL v1.0, v1.1, and v1.2.
- **Browser Compatibility**: Compatible with all modern evergreen browsers supporting WebAssembly and Web Workers (Chrome 80+, Firefox 78+, Safari 14.1+, Edge 80+).
- **Offline / Air-Gapped Ready**: The compiled WebAssembly bundle and portal assets operate 100% offline once cached by the browser service worker.
